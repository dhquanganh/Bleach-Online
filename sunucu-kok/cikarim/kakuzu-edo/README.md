# Kakuzu [Edo Tensei]

Local client release: `2026102701`. Hero `11120997`, Water Clone `11120998`, SSS, all formation slots. Tags: Earth, Male, Hidden Waterfall, Akatsuki, Secret Jutsu User, Edo Tensei. The existing admin overlay excludes IDs `11120900–11120999`.

Modify Fragment `14130997` and Recruit Token `14140997` use the source head icon. The normal inventory token gives the hero; duplicate ownership leaves the token untouched. Water Clone is summon only.

Every damaging move uses `attackStat: "atk"` and `damageType: "physical"`. The physical hit formula reads buffed Physical ATK and Physical DEF. Source descriptions are imported from `asset/Kakuzu_Edo_Tensei_Full`, with the requested screenshot wording for Heart Capture, the three additional skills and Reattachment. The screenshot supplies no damage coefficients, so the local values in `sunucu/kakuzu-edo.json` are: Heart Capture 1.45, Taijutsu Attack 1.0, clone attack 0.65, and additional skills 0.55.

The Water Clone starts with 90% of Kakuzu's max HP. While it lives, Kakuzu survives fatal Mystery damage, including legacy instant defeat. A standard attack queues one random Wind, Lightning or Fire additional skill. Wind damages a random enemy row, applies Discouragement and raises allied initiative 3% through the next round. Lightning applies Paralysis through the round and reduces Mystery cooldown by one. Fire suppresses immunity for the round and clears Kakuzu's Ignition. Heart Capture ignores shields and interruption, gains critical chance below 15% target HP, removes Fear, and on a kill heals 20% max HP and increases Physical ATK 40%. Kakuzu is immune to debuffs and has a high chance to evade chase damage. Living Kakuzu and Water Clone each use Reattachment at round end to revive a random defeated ally at 30% HP; the clone can do this while controlled. Kakuzu's own fatal damage schedules Reincarnation for the next round at 25% HP, cleanses debuffs, resets Mystery cooldown, and summons the clone again. No one time limit is added to this passive.

Native actor frames retain source pivots, aspect ratios and lossless alpha. Profile idle has a stable canvas and is positioned 10 px lower. The Water Clone shares Kakuzu's native model through RoleModel, including the entry and death timelines, eliminating duplicate model downloads. Skill effects use the supplied SWFs and separate actor scoped layers. The skill layers and clone pose listeners clear on reset, interruption, death and stage removal. The eight effect SWFs total about 16 MiB; the shared actor atlas is about 8.5 MiB, close to Tobi's combined native download size.

Build sequence: `prepare-assets.py`, `build.py`, `build-fragments.py --apply`, `../ninja-fragments/build-recruit-items.py --apply`, `build-client.py`, `build-probe.py`, `build-clone-probe.py`, run both native probes, then `release.py`. The release script checks the current active client and writes a fresh resource manifest without replacing unrelated entries.
